## About Me

I build research-driven ML systems from problem framing to reproducible training, evaluation, and documentation. My strongest work sits at the intersection of model performance, experiment design, and repository quality, so reviewers can inspect both the ideas and the implementation.

My recent work includes:

- sarcasm and sentiment classification across English varieties with encoder, decoder, and adapter-based pipelines
- multimodal wildfire burned-area prediction from pre-fire satellite, terrain, weather, and infrastructure signals
- robust MuJoCo locomotion with PPO, curriculum domain randomization, and entropy scheduling
- local MLOps platform setup with Kubernetes, Istio, Katib, and browser-based development workflows

| [RL](https://github.com/josephfayyaz/RL) | MuJoCo Hopper transfer-learning study showing `PPO + CDR + ES` improved cumulative return by `72%` over vanilla PPO and delivered more than `4x` the return of PPO with uniform domain randomization. | `Python` `MuJoCo` `PPO` `Robust RL` |
| [ML_Ops](https://github.com/josephfayyaz/ML_Ops) | Laptop MLOps lab that provisions a local private-cloud style workflow using `kind`, `MetalLB`, `Istio`, `Katib`, and `code-server`, with architecture and deployment documentation included. | `Python` `Kubernetes` `kind` `Istio` `Katib` `Docker` |
